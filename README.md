# AickaraWinUtil

A lightweight **Windows PowerShell utility** for system optimization, cleanup, troubleshooting, diagnostics, application management, and Windows configuration.

Designed to provide a convenient set of tools for maintaining and configuring Windows systems from a single elevated PowerShell session.

---

## Quick Start

> **AickaraWinUtil requires Administrator privileges** for system-level operations.

Open **PowerShell** or **Windows Terminal** as Administrator and run:

```powershell
irm "https://raw.githubusercontent.com/Vengeance239/aickarawinutil/refs/heads/main/aickarawinutil.ps1" | iex
```

---

## Features

* **Package Optimizations** — Predefined optimization profiles for Office, Laptop, Performance, and Gaming.
* **Cleanup** — Remove temporary files, cache, and other unnecessary data.
* **Fixes** — Common Windows, network, and system troubleshooting tools.
* **Windows Activation** — Access to supported activation utilities.
* **App Management** — Install and update applications using Winget or Chocolatey.
* **Diagnostics** — System information, network tests, power configuration, and system health checks.
* **Remote Assistance** — Optional setup for remote support.

---

## Requirements

* Windows 10 / 11
* PowerShell 5.1+
* Administrator privileges
* Internet connection for online features

---

## Usage

Run the command above from an **Administrator PowerShell** session and follow the on-screen menu.

```text
AICKARA WINUTIL

[1] Package Optimizations
[2] Cleanup
[3] Fixes
[4] Activate Windows
[5] Install / Update Apps
[6] Diagnose
[0] Exit
```
